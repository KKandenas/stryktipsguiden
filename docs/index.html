    • Under varje tecken står chans · streck i procent. Chansen kommer från bookmakerodds, strecken visar hur svenska folket spelat.
    • Orange prick = understreckat. Chansen är minst 3 procentenheter högre än strecken. Går tecknet in delar färre på potten.
    • Blå rutor är tecknen i ditt system. SPIK = ett tecken, HALV = två, HEL = alla tre.
    • Tryck på ett tecken för att låsa det 🔒. Resten räknas om runt dina låsningar. Tryck på matchen för att visa kommentaren, oddsen och tipsen.
